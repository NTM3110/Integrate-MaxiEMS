# Cấu hình TCP dùng chung

Thư mục dành cho dịch vụ cấu hình TCP dùng chung khi được triển khai. Hiện tại
transport Modbus TCP và cấu hình bridge nằm trong
`platform/protocols/io.openems.edge.bridge.modbus`. Không sao chép transport này
vào từng ứng dụng. Chưa tạo bundle rỗng hay API TCP mới trong lần di chuyển này.
